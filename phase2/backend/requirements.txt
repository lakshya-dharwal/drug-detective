# Drug Detective — backend runtime.
#
# Python 3.11 or 3.12. NOT 3.13/3.14: crewai pulls tiktoken, which has no wheel
# for those yet and needs a Rust toolchain to build from source.
#
# Versions are deliberately left unpinned here. crewai and daytona both carry
# narrow pins on shared transitive deps (httpx, pydantic, fastapi), and adding
# our own floors on top made `pip install -r requirements.txt` unresolvable from
# a clean environment. Letting the libraries agree among themselves resolves.
# For a byte-identical environment use requirements.lock.txt instead.

# --- API layer ---
fastapi
uvicorn[standard]
python-dotenv
supabase

# --- Phase 1 pipeline runtime (imported as a module) ---
requests
pandas
pydantic

# --- Display-only LLM summaries (optional; used only if OPENAI_API_KEY is set) ---
openai

# --- Agent integrations (all optional at runtime; the loop degrades without them) ---
crewai
daytona

# --- Dev only ---
pytest
